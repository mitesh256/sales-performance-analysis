# Sales Performance Analysis Using Excel

## Project Overview
This project analyzes sales data using Microsoft Excel to understand revenue, profit, product category performance, regional performance, and monthly sales trends.

## Objectives
- Analyze total sales and total profit.
- Compare sales and profit across product categories.
- Identify high-performing regions.
- Analyze monthly sales trends.
- Review key business performance indicators.

## Tools Used
- Microsoft Excel
- Excel formulas: SUM, SUMIF, COUNTIF, COUNTA, IFERROR
- Data tables and filtering
- Charts and data visualization

## Dataset
The dataset contains **600 synthetic sales records** created for practice and learning. It does not represent real company data.

Key columns include:
- Order ID and Order Date
- Region
- Category and Product
- Quantity and Unit Price
- Discount
- Sales, Cost, and Profit
- Customer Segment and Month

## Workbook Structure
- **Read Me:** Project overview, objectives, and workflow
- **Data:** Sales dataset
- **Summary:** KPIs and category, regional, and monthly summaries with charts
- **Analysis Tasks:** Tasks for data quality checks and further analysis

## Key Performance Indicators
- Total Sales
- Total Profit
- Order Records
- Units Sold
- Profit Margin
- Average Sales per Order

## Analysis Areas
1. Category-wise sales and profit
2. Region-wise sales and profit
3. Monthly sales trends
4. Product-level analysis tasks
5. Business recommendations based on verified results

## Important Note
This is a portfolio practice project using synthetic data. Findings should not be interpreted as actual business performance.
